# Experimental Figures and Visualizations

This directory contains visualizations generated during the speech signal processing and machine learning experiments.

## Stage 1 — Audio Preprocessing
- Original and preprocessed audio waveform comparisons.
- Audio signal normalization and noise reduction visualizations.

## Stage 2 — Acoustic Feature Extraction
- Acoustic feature distribution plots.
- MFCC and other spectral feature visualizations.

## Stage 3 — Feature Selection
- Feature importance rankings.
- Feature selection algorithm comparisons.
- Classification performance across feature subset sizes (k = 15, 30, 45).

## Stage 4 — Machine Learning Classification
- Classifier accuracy and macro F1-score comparison charts.
- Confusion matrices.
- Cross-validation performance visualizations.
- Computational time comparisons.
