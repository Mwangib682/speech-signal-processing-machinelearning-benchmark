Source Code

This directory contains the Python implementation of the four experimental stages:

1. `01_audio_preprocessing.py` — Audio standardization, noise reduction, and normalization.
2. `02_feature_extraction.py` — Extraction of 95 acoustic features from speech recordings.
3. `03_feature_selection.py` — Comparative evaluation of seven feature selection algorithms.
4. `04_machine_learning_classification.py` — Comparative evaluation of eight machine learning classifiers.
